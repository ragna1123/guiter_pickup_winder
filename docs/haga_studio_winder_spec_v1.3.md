# Haga Studio Pickup Winder 仕様書（ver.1.3）

## 起動シーケンス
1. 電源ON  
2. **Ver.x.x** を3秒表示  
3. **haga studio** を1秒表示  
4. メニュー画面へ遷移  

---

## メニュー構成
- **フリーカウント**
- **カウント**
- **設定**

操作：ロータリースイッチで選択、プッシュで決定。

---

## 共通仕様

### 回転カウント（RUN中）
- **片側センサ（A）の片エッジ検出**のみで加算（例：立ち上がり）。  
- スリット数：4 → **1回転 = 4パルス（Aの片エッジのみ）**。  
- RPMはこの**RUN中のパルス**からのみ算出（式は後述）。

### ポーズ／一時終了中の回転検出（手巻き補正）
- **A・B 2センサの位相（疑似クアドラチャ）**で**回転方向を判定**し、  
  正方向は**加算**、逆方向は**減算**して巻き数に**リアルタイム反映**する。  
- この期間のパルスは**RPM計算には使用しない**（手戻し・追い巻き補正のみ）。
- カウント方式は既定で **X2**（Aの両エッジでカウント、Bで方向判定）。  
  - 1回転あたりのパルス数（ポーズ中）＝ `SLOTS × 2`  
  - 安定性重視。必要に応じてX1/X4へ切替可能（設定で将来対応）。

### 表示項目
- 出力：PWM Duty（%）  
- 速度：実測RPM（RUN中の計測窓で算出）

### LED挙動
| 状態 | 青LED | 赤LED |
|------|--------|--------|
| 正転 | 点灯 | 消灯 |
| 逆転 | 消灯 | 点灯 |
| 待機中 | 選択中方向のみ点滅 | もう一方は消灯 |

## フリーカウントモード

### 流れ
1. 方向選択  
2. スタート待ち  
3. ラン（A片エッジで加算・RPM算出）  
4. ポーズ（A停止 / A・Bで方向判定し加減算）  
5. 終了時：リザルト画面 → メニューへ戻る

### 操作（RUN中）
- ロータリースイッチ回転で **出力(PWM)** を ±Δ% 変更（デフォルトΔ=1%、範囲0〜100%）。  
- 実出力はソフトチェンジで滑らかに追従。  
- 右端表示：「PUSH→PAUSE / 回して速度±」。

### 画面表示
```
[Free Count]
巻き数：NNNN
出力：DD%   速度：RRR rpm
右端：PUSH→PAUSE / 回して速度±
```

---

## カウントモード

### 流れ
1. 方向選択  
2. 目標巻数設定  
3. スタート待ち  
4. ラン（A片エッジで加算・RPM算出）  
5. ポーズ（A停止 / A・Bで方向判定し加減算）  
6. 目標到達時：一時停止 → 「追加巻」or「終了」  
7. 終了時：リザルト画面 → メニューへ戻る

### 操作（RUN中）
- ロータリースイッチ回転で **出力(PWM)** を ±Δ% 変更（デフォルトΔ=1%、範囲0〜100%）。  
- 実出力はソフトチェンジで滑らかに追従。  
- 右端表示：「PUSH→PAUSE / 回して速度±」。

### 画面表示
```
[Count Mode]
巻き数：NNNN / 目標：TTTT（追加時は合算表示）
出力：DD%   速度：RRR rpm
右端：PUSH→PAUSE / 回して速度±
```

## 方向選択（UI）
- 「→ 正転」「← 逆転」をロータリーで選択。  
- 選択方向のLEDのみ点滅。  
- プッシュで確定 → 点灯状態へ。

---

## ソフトスタート／ストップ
- 設定秒数に応じてPWM dutyを線形変化。  
  - スタート：0 → 目標値  
  - ストップ：目標値 → 0  

---

## 例外処理
### 無検出タイムアウト
- **RUN中に2秒以上パルス未検出** → モーター停止。  
- 画面表示：`ERROR: No pulse`。  
- 状態遷移：エラー → 一時停止状態へ。  
- 再開選択で通常復帰可能。

---

## 計測・換算ロジック

### RUN中のRPM
```
rpm = (pulses_run / SLOTS) * (60 / Δt)
```
- `SLOTS = 4`  
- `Δt` は計測窓（例：0.3s → 60/0.3 = 200）  
- `pulses_run` は **A片エッジのみ**で集計したパルス数。

### 巻き数（総カウント）
- **RUN中**：
  ```
  winding += pulses_run / SLOTS
  ```
- **ポーズ／一時終了中**（手巻き補正；A・B位相で方向判定、X2既定）
  ```
  delta_rev = pulses_pause_signed / (SLOTS * 2)  // X2
  winding   = max(0, winding_saved + delta_rev)  // 0未満は禁止
  ```
  - `pulses_pause_signed` は**符号付き**で加算（正：追い巻き、負：手戻し）。  
  - 表示はリアルタイム更新、RPMは更新しない。

## 実装指針（ISR/メイン分担）

### 変数
```cpp
// RUN用
volatile unsigned long run_pulses = 0;   // A片エッジのみ

// ポーズ用（手巻き補正）
volatile long pause_pulses_signed = 0;   // A両エッジで±1加算（X2）

// エンコーダ（速度調整）
volatile int enc_delta = 0;
```

### ISR（概略）
```cpp
// RUN中：A立ち上がりのみ
void IRAM_ATTR isr_run_A_rise() { run_pulses++; }

// ポーズ中：Aの立ち上がり/下がりの両方で呼び、Bで方向判定（X2）
void IRAM_ATTR isr_pause_A_edge() {
  int b = digitalRead(pinB);
  pause_pulses_signed += (b ? +1 : -1); // 位相で±を決定
}

// エンコーダ（速度調整）：AエッジでBを見て±
void IRAM_ATTR isr_encA_edge() {
  enc_delta += (digitalRead(encB) ? +1 : -1);
}
```

### メイン周期処理（例：100〜300ms）
```cpp
// RUN中
noInterrupts();
unsigned long p = run_pulses; run_pulses = 0;
interrupts();

float rev = float(p) / SLOTS;
rpm = rev * (60.0f / dt);   // dt = 周期秒
winding += rev;

// ポーズ中（リアルタイム補正；RPMは更新しない）
noInterrupts();
long ps = pause_pulses_signed;
interrupts();

float delta_rev = float(ps) / (SLOTS * 2.0f); // X2
winding = max(0.0f, winding_saved + delta_rev);
```

## 推奨パラメータ
| 項目 | 値 | 備考 |
|------|----|------|
| スリット数（SLOTS） | 4 | |
| RUN計測窓（Δt） | 0.3 s | rpm表示の安定化 |
| ポーズ時カウント方式 | X2 | A両エッジ＋Bで方向 |
| LED点滅周期 | 約400ms | |

## 付記
- 将来的に **X4（A/B両チャネル両エッジ）**に切替可能。分解能は上がるが、手巻きの微振動を拾いやすくなるため既定はX2。  
- ポーズ時の補正は**巻き数のみ**に適用し、**RPMには反映しない**。  
- 巻き数は下限0を維持（マイナス禁止）。
